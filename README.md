# 네이버 쇼핑 바로검색

쇼핑몰에서 보고 있는 상품을 네이버 쇼핑에서 바로 검색해 주는 Chrome 익스텐션이다. 툴바 아이콘을 누르면 지금 열려 있는 상품 페이지에서 상품명을 읽어 입력란에 채워 주고, Enter를 누르면 그 상품명으로 네이버 쇼핑 검색 결과 탭이 열린다. 무신사, 29CM, G마켓, 11번가, 쿠팡처럼 페이지 구조가 제각각인 사이트를 사이트별 규칙 없이 처리하려고 JSON-LD와 og:title 같은 공통 메타데이터만 읽는다. 네이버 API를 쓰지 않으므로 키 발급이나 설정이 필요 없고, 외부로 보내는 요청도 없다.

## 설치

Chrome 웹 스토어에 올리지 않았으므로 압축해제 로드 방식으로 설치한다.

1. 이 저장소를 내려받는다.
2. Chrome에서 `chrome://extensions`를 열고 오른쪽 위 "개발자 모드"를 켠다.
3. "압축해제된 확장 프로그램을 로드합니다"를 누르고 이 폴더를 고른다.
4. 툴바의 퍼즐 아이콘에서 "네이버 쇼핑 바로검색"을 고정해 두면 편하다.

빌드 과정이 없어서 폴더를 그대로 로드하면 된다. 필요한 권한은 `activeTab`, `scripting`, `contextMenus` 세 가지이며 특정 사이트에 대한 상시 접근 권한은 요구하지 않는다. 아이콘을 누른 그 탭에 대해서만, 누른 순간에만 페이지를 읽는다.

## 사용법

상품 페이지에서 툴바 아이콘을 누르거나 Alt+Shift+N을 누르면 팝업이 뜨고 입력란에 상품명이 채워진 채 전체 선택된 상태로 커서가 들어가 있다. 그대로 Enter를 치면 네이버 쇼핑 검색 탭이 열리고, 채워진 상품명이 마음에 안 들면 바로 타이핑해서 고친 뒤 Enter를 치면 된다. "통합검색으로" 링크를 누르면 네이버 쇼핑 대신 네이버 통합검색 결과가 열린다.

페이지에서 텍스트를 드래그한 상태로 아이콘을 누르면 상품명 추출을 건너뛰고 드래그한 텍스트가 그대로 입력란에 들어간다. 드래그한 텍스트를 우클릭하면 "'…' 네이버 쇼핑에서 검색" 메뉴가 보이는데, 이것은 팝업 없이 바로 검색 탭을 연다. 두 경우 모두 100자까지만 쓴다.

상품명을 못 찾으면 입력란을 비워 두고 "상품명을 찾지 못했습니다. 직접 입력하세요."라고 알려 준다. `chrome://` 페이지나 웹 스토어처럼 익스텐션이 읽을 수 없는 탭에서는 "이 페이지에서는 상품명을 읽을 수 없습니다."가 뜨지만 직접 입력해서 검색하는 것은 가능하다.

## 상품명을 찾는 방법

페이지의 네 가지 신호를 순서대로 본다. 먼저 `<script type="application/ld+json">` 안의 `Product` 항목에서 `name`과 `brand`를 읽는다. 이 경로가 가장 깨끗한데, 조사한 사이트의 대부분이 상품명을 여기에 그대로 넣어 두기 때문이다. 옵션(색상, 사이즈)마다 `Product`를 하나씩 넣는 cafe24 계열 쇼핑몰은 항목들의 공통 접두사를 상품명으로 삼고, 추천 상품 목록까지 `Product`로 넣어 둔 사이트는 og:title이나 제목과 단어가 가장 많이 겹치는 항목을 고른다. JSON-LD의 이름이 영문뿐이고 og:title이나 h1에 모델명이 겹치는 한글 이름이 있으면 한글 쪽을 쓴다.

JSON-LD가 없으면 `og:title`, 그다음 `<title>`, 마지막으로 `<h1>`을 본다. og:title과 제목에는 "| 무신사", "- 사이즈 & 후기", ":: 라운즈" 같은 사이트명과 상용구가 붙어 있으므로 구분자로 쪼개서 사이트명이 든 구간과 짧은 상용구 구간을 버리고 가장 긴 구간을 남긴다. 그렇게 얻은 이름이 h1으로 시작하면 h1을 쓴다. 쿠팡처럼 og:title에 "루나미 소프트 오버나이트 - 일반 오버나이트"라고 카테고리를 덧붙이는 경우를 h1이 바로잡아 준다.

고른 이름에는 마지막으로 정리 규칙을 적용한다. 대괄호는 "[무료배송]", "[3옵션]"처럼 광고 단어가 들어 있거나 "[11/27 예약발송]"처럼 숫자와 슬래시가 함께 들어 있으면 지우고, 소괄호는 "(MADE/3기장/S~XL)"처럼 광고 단어와 슬래시가 함께 들어 있을 때만 지운다. 그래서 "(1.25L/2개)" 같은 용량 표기는 남는다. "(빅사이즈팬츠-스판슬랙스-스판팬츠-하객룩)"처럼 구분자가 세 개 이상 든 검색어 나열 괄호를 지우며, 이모지와 "-FREE", "-2colors", "-250"(신발 사이즈) 같은 옵션 꼬리를 떼고, 60자가 넘으면 단어 경계에서 자른다. "9-95"처럼 두 자리 숫자로 끝나는 모델명은 옷 사이즈와 구분할 수 없어 그대로 둔다. 브랜드 이름이 따로 있고 상품명에 안 들어 있으면 앞에 붙인다. 이 규칙은 모두 `extractor.js` 한 파일에 있고, 사이트 주소를 보고 분기하는 코드는 없다.

## 조사 근거

2026-11-06에 한국 쇼핑몰 213곳(종합/오픈마켓 45, 패션 90, 뷰티 25, 전자 15, 리빙 15, 식품 11, 기타 12)을 돌며 상품 페이지의 메타데이터를 확인했다. 상품 페이지를 실제로 열어 본 127곳 전부에서 위 규칙으로 검색어를 만들 수 있었고, 그중 90곳은 JSON-LD에, 37곳은 og:title이나 제목, h1에 상품명이 있었다. 나머지 86곳은 자동화 브라우저 차단(44곳)이나 홈에서 상품 링크를 자동으로 못 찾은 경우(42곳)라 미확인이며, 실패했다는 뜻이 아니라 검증하지 못했다는 뜻이다. 사이트별 결과와 실제로 만들어진 검색어 전체 목록은 `docs/survey/README.md`에 있다.

127곳의 메타 신호와 기대 검색어는 `tests/fixtures/sites.json`에 들어 있고 테스트가 이 파일을 돌려 추출 규칙이 바뀔 때 어느 사이트의 결과가 달라지는지 바로 보여 준다.

## 테스트

Node 22 이상이 필요하고 설치할 패키지는 없다.

```
npm test
```

`tests/extractor.test.js`는 정리 함수와 후보 선택 규칙의 단위 테스트, 127곳 픽스처 회귀 테스트, 가짜 document로 돌리는 DOM 수집 테스트를 담고 있고 `tests/naver.test.js`는 검색 URL 인코딩을 확인한다. 팝업과 우클릭 메뉴는 자동 테스트가 없으므로 아래 목록을 직접 확인한다.

## 직접 확인할 목록

익스텐션을 로드한 뒤 아래 사이트의 아무 상품 페이지에서 아이콘을 눌러 입력란에 채워지는 값과 Enter로 열리는 탭을 본다. 조사 때 자동화 브라우저가 차단된 사이트가 많아 실제 브라우저에서의 확인이 필요하다.

| 사이트 | 조사에서 본 경로 | 확인할 점 |
| --- | --- | --- |
| 쿠팡 | og:title, h1 | h1 덕분에 카테고리 꼬리가 빠지는지 |
| G마켓 | JSON-LD | og:title이 잘려 있어도 JSON-LD로 전체 이름이 나오는지 |
| 옥션 | JSON-LD | 브랜드가 앞에 붙는지 |
| 11번가 | JSON-LD | "[11번가]" 접두사가 안 들어가는지 |
| SSG닷컴 | JSON-LD | 긴 이름이 60자에서 단어 경계로 잘리는지 |
| 무신사 | JSON-LD | "브랜드 상품명_모델코드" 형태가 나오는지 |
| 29CM | JSON-LD | "모든 취향 곁에, 29CM"가 빠지는지 |
| 올리브영 | og:title | 올영픽 같은 행사 대괄호가 빠지는지 |
| 오늘의집 | JSON-LD | 브랜드가 앞에 붙는지 |
| 에이블리 | og:title | 모바일 페이지에서도 채워지는지 |

네이버 쇼핑이 검색 결과 대신 접근 차단 안내를 보여 주면 "통합검색으로" 링크를 쓰면 된다.

## 한계

핫핑, 육육걸즈, 고고싱처럼 자체 제작 상품을 파는 여성 의류몰은 상품명 자체가 "[바스락와샤카고6만3천장] 썸머 투웨이 밴딩 와샤 카고팬츠 (여름긴바지,나일론팬츠,…)"처럼 광고 문구로 돼 있어서 정리 규칙을 거쳐도 네이버에서 같은 상품이 잘 안 나온다. 자체 제작 상품이라 네이버에 같은 상품이 없는 경우도 많다.

"[29EDITION X 아우어솔티]" 같은 협업 표기는 광고 대괄호와 구분할 방법이 없어서 안에 슬래시나 물결이 함께 들어 있으면 지워질 수 있다. 반대로 "[퓨어이지]"처럼 광고 단어가 없는 소분류 대괄호는 남는다.

페이지를 다 그린 뒤에 메타 태그를 바꾸는 단일 페이지 앱은 아이콘을 누르는 시점에 따라 이전 상품의 이름이 나올 수 있다. 그런 경우 입력란의 값을 고치거나 텍스트를 드래그한 뒤 누르면 된다.

네이버 쇼핑 검색 페이지는 자동화 브라우저에 접근 차단(418) 페이지를 돌려주었고 일반 사용자 브라우저에서 정상 동작하는지는 조사 환경에서 확인하지 못했다. 네이버 스마트스토어 상품 페이지도 조사 환경에서는 로그인 화면으로 넘어가 확인하지 못했다.

조사한 213곳 중 86곳은 위에 적은 대로 미확인이고, 조사에 없는 사이트는 같은 규칙이 통할 가능성이 높지만 보장은 없다. 어느 사이트에서 엉뚱한 값이 채워지면 팝업에서 고쳐 쓰는 것이 이 익스텐션의 기본 대응이며 사이트별 규칙은 추가하지 않는다.
