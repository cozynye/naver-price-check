# Chrome 웹 스토어 등록 정보

[개발자 대시보드](https://chrome.google.com/webstore/devconsole)의 각 칸에 붙여 넣을 내용을 모아 둔 문서다. 업로드할 zip은 `scripts/package.sh`로 만들고(`dist/naver-price-check-<버전>.zip`), 이미지 파일은 이 폴더에 있다.

## 패키지

`scripts/package.sh`는 테스트를 먼저 돌린 뒤 `manifest.json`, `background.js`, `extractor.js`, `naver.js`, `popup.*`, `icons/`만 zip에 담는다. 새 버전을 올릴 때는 `manifest.json`과 `package.json`의 `version`을 함께 올린 다음 다시 실행한다. 스토어는 같은 버전 번호의 재업로드를 받지 않는다.

## 스토어 등록정보 탭

| 항목 | 값 |
| --- | --- |
| 이름 | 네이버 쇼핑 바로검색 (manifest에서 읽힘) |
| 요약 | 보고 있는 상품을 네이버 쇼핑에서 바로 검색해 가격을 비교한다. (manifest에서 읽힘) |
| 카테고리 | 쇼핑 |
| 언어 | 한국어 |
| 스토어 아이콘 | zip 안의 `icons/icon128.png` |
| 스크린샷 (1280×800) | `screenshot-1.png`, `screenshot-2.png` |
| 작은 프로모션 타일 (440×280) | `promo-tile-440x280.png` |
| 홈페이지 URL | https://github.com/cozynye/naver-price-check |
| 지원 URL | https://github.com/cozynye/naver-price-check/issues |

스크린샷은 가상의 쇼핑몰 페이지(`shop.example.com`, 브랜드 "온스텝")에 실제 `popup.html`, `popup.css`, `extractor.js`를 띄워 찍었다. 브라우저 테두리와 툴바는 그림으로 그린 것이고 확장 API 호출만 대체했으며, 입력란 값은 `extractor.js`가 그 페이지에서 직접 뽑은 결과다.

### 설명

```
쇼핑몰에서 보고 있는 상품을 네이버 쇼핑에서 바로 검색해 주는 익스텐션이다. 툴바 아이콘을 누르거나 Alt+Shift+N을 누르면 지금 열려 있는 상품 페이지에서 상품명을 읽어 입력란에 채워 주고, Enter를 누르면 그 상품명으로 네이버 쇼핑 검색 결과가 새 탭에 열린다. 채워진 이름이 마음에 들지 않으면 바로 고쳐서 검색하면 되고, "통합검색으로"를 누르면 네이버 통합검색 결과가 열린다.

상품명은 페이지에 들어 있는 JSON-LD 상품 정보와 og:title, 페이지 제목, h1을 차례로 보고 고른다. "[무료배송]" 같은 광고 대괄호, "| 쇼핑몰이름" 같은 사이트명, "-FREE"나 "-250" 같은 옵션 꼬리는 지우고 브랜드가 따로 있으면 앞에 붙인다. 사이트별 규칙 없이 공통 메타데이터만 쓰며, 국내 쇼핑몰 127곳의 상품 페이지로 이 규칙을 확인했다.

페이지에서 텍스트를 드래그한 채로 아이콘을 누르면 드래그한 텍스트로 검색하고, 드래그한 텍스트를 우클릭하면 "네이버 쇼핑에서 검색" 메뉴로 팝업 없이 바로 검색 탭을 연다.

아이콘을 누른 탭에서, 누른 순간에만 페이지를 읽는다. 읽은 내용은 어디로도 보내지 않고 저장하지도 않으며, 익스텐션이 만드는 네트워크 요청은 없다. 검색 결과 탭을 여는 것이 전부다.

자체 제작 상품처럼 상품명이 광고 문구로 이뤄진 경우에는 정리 후에도 네이버에서 같은 상품이 잘 나오지 않을 수 있다. 이 익스텐션은 네이버와 관련 없는 개인 개발 프로젝트이며 소스 코드는 https://github.com/cozynye/naver-price-check 에 공개되어 있다.
```

## 개인정보 보호 탭

### 단일 목적

```
현재 보고 있는 상품 페이지에서 상품명을 읽어 네이버 쇼핑 검색 결과를 새 탭으로 연다.
```

### 권한 사용 근거

| 권한 | 근거 |
| --- | --- |
| activeTab | 사용자가 툴바 아이콘이나 단축키를 누른 그 탭에 한해서 상품명을 읽기 위해 필요하다. 상시 사이트 접근 권한은 요청하지 않는다. |
| scripting | activeTab으로 허용된 탭에 상품명 추출 스크립트(extractor.js)를 주입해 결과를 팝업으로 받기 위해 필요하다. |
| contextMenus | 드래그한 텍스트를 우클릭했을 때 "네이버 쇼핑에서 검색" 메뉴를 보여 주기 위해 필요하다. |

호스트 권한은 없으므로 이 칸은 비워 둔다.

### 원격 코드

"아니요, 원격 코드를 사용하지 않습니다"를 고른다. 모든 스크립트가 패키지 안에 있고 `eval`이나 외부 스크립트 로드가 없다.

### 데이터 사용

수집하는 사용자 데이터 항목은 하나도 체크하지 않는다. 페이지에서 읽은 상품명은 팝업 입력란과 사용자가 여는 네이버 검색 URL에만 쓰이고, 익스텐션이 저장하거나 전송하지 않는다. 아래 세 가지 준수 항목에는 모두 체크한다.

- 승인된 사용 사례 외의 목적으로 사용자 데이터를 판매하거나 전송하지 않음
- 단일 목적과 관련 없는 목적으로 사용자 데이터를 사용하거나 전송하지 않음
- 신용도 판단이나 대출 목적으로 사용자 데이터를 사용하거나 전송하지 않음

개인정보처리방침 URL은 사용자 데이터를 다루는 익스텐션에만 필수다. 칸을 채워야 한다면 README의 권한 설명이 있는 https://github.com/cozynye/naver-price-check#설치 를 넣는다.
