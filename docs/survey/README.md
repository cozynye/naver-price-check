# 한국 쇼핑몰 213곳 상품명 추출 가능성 조사

조사일: 2026-11-06. 대상 213곳(종합/오픈마켓 45, 패션 90, 뷰티 25, 전자 15, 리빙 15, 식품 11, 기타 12).

## 방법

각 사이트의 홈(또는 랭킹/베스트 페이지)에서 상품 상세 페이지 링크를 자동으로 찾아 들어간 뒤, 그 페이지에서 상품명을 뽑을 수 있는 경로가 있는지 확인했다. 확인한 경로는 JSON-LD `Product`의 `name`/`brand`, `og:title`, `og:site_name`, `og:type`, 가격 메타(`product:price:amount`), `<title>`, `<h1>`이다. 1차는 HTTP 요청(서버 렌더링 HTML), 2차·3차는 headless Chrome(자동화 탐지 우회 플래그 없음), 일부 주요 사이트(쿠팡, G마켓, 옥션, 11번가, SSG, 올리브영, 오늘의집, 에이블리, 카카오톡 선물하기)는 창이 있는 Chrome으로 직접 열어 확인했다. 그런 다음 익스텐션에 넣을 추출 규칙(아래 "추출 규칙")을 저장된 페이지에 그대로 적용해 실제로 어떤 검색어가 만들어지는지 뽑았다.

자동화 환경이라는 한계가 있다. 봇 차단(403/418/로그인 리다이렉트)에 걸린 사이트는 "미확인"으로 두었고, 홈에서 상품 링크를 자동으로 못 찾은 사이트도 "미확인"이다. 두 경우 모두 사용자의 실제 브라우저에서는 페이지가 열리므로 익스텐션이 실패한다는 뜻이 아니라, 이 조사에서 검증하지 못했다는 뜻이다.

## 추출 규칙 (조사 결과로 확정)

1. JSON-LD `Product`가 하나면 그 `name`을 쓴다. 여럿이면 옵션별 변형(카페24 계열: "상품명 퍼플-FREE", "상품명 카키-FREE")인지 추천 상품 목록(아모레몰처럼 20개)인지 구분한다. 변형이면 이름들의 공통 접두사를, 목록이면 og:title·title과 단어가 가장 많이 겹치는 항목을 고른다. 겹침이 절반 미만이면 JSON-LD를 버린다.
2. JSON-LD가 없으면 og:title에서 사이트명 구간을 떼어낸다. 구분자(` | `, ` - `, ` :: `, ` : `, ` by `)로 나눈 뒤 og:site_name이나 호스트명(musinsa, 29cm 등)과 겹치는 구간, "공식 온라인 스토어"·"사이즈 & 후기" 같은 짧은 상용구 구간을 버리고 가장 긴 구간을 남긴다.
3. og:title도 없으면 `<title>`에 같은 처리를, 그다음 `<h1>`을 본다. 쿠팡처럼 h1이 og:title의 앞부분(옵션 없는 이름)이면 h1을 우선한다.
4. 정리: HTML 태그 제거(핫핑 JSON-LD에 `<b>`, `<br>`이 들어 있음), 이모지 제거, 광고성 대괄호·소괄호 제거(`[무료배송]`, `[3옵션]`, `(국내제작)(MADE/3기장/S~XL/탑셀러!)` 등. 숫자+슬래시·물결이 있거나 할인·배송·특가류 단어가 있는 괄호만 제거하고 `[Black Diamond]`, `[ThalaSpa]` 같은 브랜드 괄호는 남긴다), 구분자가 3개 이상 든 괄호(검색어 나열 `(빅사이즈팬츠-스판슬랙스-...)`) 제거, 60자에서 단어 경계로 자르기.
5. JSON-LD에 brand가 있고 상품명에 그 브랜드가 없으면 앞에 붙인다("아디다스 레알 마드리드 써드 저지 14/15 KF4243").
6. 어떤 규칙도 결과를 못 내면 팝업 입력란을 빈 채로 열고, 사용자가 드래그한 텍스트가 있으면 그것을 우선 채운다.

## 눈에 띄는 한계

- 여성 쇼핑몰(핫핑, 육육걸즈, 고고싱, 리리앤코 등)은 상품명 자체가 광고 문구와 검색어 나열로 채워져 있어 정리 규칙을 거쳐도 네이버에서 같은 상품을 찾기 어렵다. 이들은 자체 제작 상품이라 다른 몰에 같은 물건이 없고, 네이버에서 찾아지는 것은 그 몰의 스마트스토어 입점 상품 정도다. 가격비교가 의미 있는 곳은 브랜드 상품을 파는 무신사·29CM·W컨셉·오픈마켓 쪽이다.
- 29CM의 `[29EDITION X 아우어솔티]`처럼 협업 이름이 대괄호에 들어간 경우 광고 태그와 구분이 안 되어 같이 지워질 수 있다. 팝업에서 검색어를 고칠 수 있게 두는 이유다.
- 아모레몰처럼 JSON-LD 이름이 영문("Ceramide Ato Lotion 350ml")이고 화면은 한글인 경우가 있어, 한글이 있는 og:title·h1을 우선하는 보정을 넣었다. 네파는 반대로 JSON-LD가 한글, og:title이 영문이다.
- 지그재그·에이블리·카카오톡 선물하기처럼 SPA인 곳은 메타가 로드 후에 채워진다. 클릭 시점에 읽으면 문제없지만, 같은 탭에서 다른 상품으로 이동한 뒤 메타가 갱신되지 않는 사이트가 있을 수 있다.
- 자동화 차단 44곳과 탐색 실패 42곳은 실제 브라우저에서 따로 확인해야 한다. 특히 위메프·이마트몰·트레이더스·신세계몰·아디다스·유니클로·자라·스마트스토어가 여기에 있다.
## 데이터

조사에서 저장한 상품 페이지의 메타 신호(og:title, og:site_name, og:type, title, h1, JSON-LD name/brand)와 추출 규칙 프로토타입이 만든 기대 검색어는 `tests/fixtures/sites.json`에 있다. 원본 HTML은 세션 임시 폴더에만 있었고 저장소에는 넣지 않았다.
